1. **B-1 还没经过你的真机验收**：代码已重构并推送，但全屏 → 竖屏 → 退出再进这条链路必须你在安卓上确认。
2. **P0-7 发布签名没改**：Release 仍可能每次 CI 签名不同；按你的要求没有自动构建 / 发布。
3. **真正 1–5 分钟视频预加载没做**：目前只显示缓冲段，不会提前强制拉取后续几分钟。
4. **视频本体持久缓存没做**：重开同一视频仍要重新联网加载视频流，只缓存了标题 / 作者 / 时长等元信息和字幕。
5. **全局清缓存不彻底**：不清 WebView HTTP 缓存、Cookie、YouTube 登录态、视频本体缓存。
6. **OpenRouter 真实请求没验证**：配置和 UI 已接通，但没有拿真实 key 跑过完整翻译。
7. **iOS Swift 没编译**：ML Kit 语言白名单、auto 语言处理都需要 macOS / 云端 iOS 构建确认。
8. **所有近期 UI / 交互改动没有真机验收**：盲听精确暂停、长字幕窗口化、横屏颜色、B-1 都在等设备确认。
9. **收藏视频 / 学习页续播没做**：收藏目前没写入 progress/duration，是否要像频道 / 播客一样续播还没定产品口径。
10. **字幕轨道和请求仍有串行点**：播放器最多仍串行请求 3 条轨道；WebView 内 fetch 没有单请求超时。
11. **历史仍保留 120 条上限**：到上限只提示，不扩容。
12. **死代码 / 半成品没清**：订阅分组 UI、播客音频模式、语速 / 音调仅试听、`interfaceLang` 仅展示等。
